# Q2 Platform Strategy Review — 2026-03-18

**Attendees**: Alice (CTO), Bob (Platform Lead), Carol (Security Lead), Dave (FinOps Manager), Eve (Infrastructure Lead)

---

Alice: Let's get through the full platform agenda today. We have four topics.

## Topic 1: Disaster Recovery Commitments

Alice: We need to formally commit to a disaster recovery standard for all Tier-1 production services.
Bob: I propose RPO of 4 hours and RTO of 8 hours for Tier-1 workloads.
Carol: Agreed. And we need a validated failover runbook for every designated failover path.
Bob: The runbook owner for each failover path must be a named individual, not a team.
Alice: Runbooks should be reviewed on a quarterly cadence. We own the DR strategy at the business level.

## Topic 2: Compute Rightsizing

Eve: We've been over-provisioning VMs. I want to mandate DS3_v2 as the standard VM SKU for production
     services, replacing the current ad-hoc SKU selection.
Bob: Agreed. We should also require that all VMs use managed disks — no unmanaged disks in production.
Eve: Spot instances should be allowed for non-production environments but not for Tier-1 production.

## Topic 3: Deployment Automation

Bob: We want to implement a fully automated deployment pipeline: engineers push to main and the system
     auto-deploys to production without any approval gate.
Alice: That would reduce cycle time significantly.
Carol: I need to stop this one. We currently have a hard requirement that ALL production deployments
       require an approved change ticket before execution. Auto-deploy to production without a change
       board approval would violate that policy directly. I can't sign off on this.
Bob: OK, noted. Can we flag it for now and revisit the approval process next quarter?
Carol: Yes, you can note the proposal but it has to be flagged as conflicting with our access-control policy.

## Topic 4: Cost Governance for New Workloads

Dave: I want to formalize that any new cloud workload expected to exceed $5,000 USD per month
      must go through a FinOps cost pre-approval before deployment.
Alice: That's sensible. And we should require a reserved instance coverage review every quarter.
Dave: We already have a ≥85% RI utilization target in place. This would add the pre-approval gate
      for net-new workloads, which is not currently in the cost spec.
